# Trippy v2: The Redesign Blueprint (PRD)

## 1. Executive Summary
Trippy v2 is an AI-native UI overhaul moving from "functional utility" to "premium digital craft." It is built on the **Jelly Liquid Glass** framework, combining the tactile physicality of glassmorphism with the playful fluidity of liquid motion.

## 2. Visual Foundation
### 2.1 Surfaces
- **Material:** 40px Backdrop Blur, 45-65% white opacity.
- **Edge:** 1px Specular Border (White 80% opacity) on top/left; 1px Shadow Border (Ink 10%) on bottom/right.
- **Corner Radius:** Minimum 24px for small cards; 32px for large containers.

### 2.2 Iconography: The Emblem System
- **Rule:** No monochrome line icons. 
- **Structure:** All icons are 80x80 SVG emblems. 
- **Language:** Every icon uses at least 3 brand colors (Forest, Terracotta, Gold) and is contained within a 2.5pt Ink ring.

## 3. The Interactive Experience
### 3.1 Fluid Sliders
- Used for: Time selection, Trip duration, Budgeting.
- Effect: "Elastic bounce" when reaching limits. The thumb should "swell" (jelly effect) when pressed.

### 3.2 Specular Motion
- All glass cards feature a subtle diagonal shine that moves based on the user's scroll velocity or device accelerometer.

### 3.3 Loading States
- The "Global Compass Loader": A central hub where the four colored diamonds spin and merge into a single drop of liquid before expanding into the next screen.

## 4. Design Metadata (The "Dots")
- **Tracking:** -0.04em for Bricolage Grotesque headlines.
- **Kerning:** Optical.
- **Whitespace Rhythm:** Multiples of 8px (base unit) but with 4px "half-steps" for tight technical meta-data.
- **Shadows:** Never pure black. Use `#1A1410` at 8% alpha with 40px spread.
