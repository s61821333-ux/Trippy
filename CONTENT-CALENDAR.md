## Content Brief: Feature Pages (Standard Template)

Each feature page must include:

1. **H1** (keyword-rich, 60–70 chars)
2. **Lead paragraph** (2–3 sentences, primary keyword in first sentence)
3. **What it is** — 100–150 words
4. **How it works in Trippy** — 150–200 words + screenshot placeholder
5. **Key sub-features** — 3–4 items, 50 words each
6. **Use case / story** — 100 words
7. **FAQ** — 3 Q&As (no FAQPage schema — commercial SaaS restriction)
8. **CTA** — "Start Planning Free" / "התחל לתכנן בחינם"

**Word count target**: 700–900 words EN + 700–900 HE

---

## Content Brief: Blog Posts (Standard Template)

1. **H1** (question-format for featured snippet eligibility)
2. **TL;DR summary** — 2 sentences
3. **Introduction** — 150 words, primary keyword in first 100 words
4. **Main sections** with H2s (ordered or listicle format)
5. **Trippy product mention** — natural integration, not forced
6. **Conclusion + CTA**

**Word count target**: 1,500–2,500 words

---

## Publishing Checklist (every page)

- [ ] Primary keyword in H1, first 100 words, meta title, meta description
- [ ] `alternates.canonical` set correctly
- [ ] `alternates.languages` (en-US + he-IL)
- [ ] `og:title`, `og:description`, `og:image` set
- [ ] Internal links: 2–3 to feature pages, 1–2 from relevant pages pointing here
- [ ] Word count meets target
- [ ] Images: alt text, Next.js `<Image />` component used
- [ ] BreadcrumbList schema added (feature + blog pages)
- [ ] Added to `app/sitemap.ts`
